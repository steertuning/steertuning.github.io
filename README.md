# Steertuning v2026.10.13.1

Research website for **Steertuning Policies from a Few Human Videos**.

Published at https://steertuning.github.io/.

This repository contains the complete static website. GitHub Pages serves `main` from the repository root. The main teaser retains its audio; all other videos have no audio streams. See `version.json` for the published version.

This release narrows the page column, aligns the human/robot overview videos, restores a compact horizontal policy network, and moves the finetuning/steering and trajectory-selection experiments below the steering animation. Full manuscript acknowledgements appear at the end of the named website.
